# Isolated interface QA

Build the frontend, then run `node --import tsx scripts/ui-qa.ts` from the repository root. Open `http://127.0.0.1:8788/`. Set `UI_QA_PORT` to another unused port if required; the harness refuses production port 8787.

The harness serves the current `dist/` build and uses the application's real paper Engine with a new temporary SQLite database on every start. It does not load `.env`, construct a live Gateway, connect venue accounts, or permit live mode. Production data and port 8787 are untouched. All positions, prices, option contracts, and fills are synthetic. Starting the harness never executes a real trade.

It intentionally implements only the API surface needed for browser UI review. This is not a replacement backend and does not validate real venue signing or exchange responses.

Switch scenarios with a JSON request to the **QA port**:

```sh
curl -s http://127.0.0.1:8788/__qa/scenario \
  -H 'Content-Type: application/json' \
  -d '{"scenario":"normal"}'
```

Reload the browser after changing presets if an open modal belongs to the old state. `GET /__qa/scenario` confirms the selected scenario.

| Scenario | Purpose |
| --- | --- |
| `normal` | Eight-asset paper portfolio, no connected wallets, six-leg default fit. The persistent paper worker is running. Quote, review, confirm simulated purchase, enable hedge, change the paper reference price, and pause all. |
| `empty` | All LP selections and inventories empty; no options or perps. Verify missing-position states and disabled actions. |
| `stale` | Market, instrument, and LP timestamps are three minutes old. Includes a stored six-leg proposal generated by the real optimizer and then expired, for stale-cost labeling and disabled-purchase checks. Worker is stopped and hedge is suspended with an explicit stale-feed reason. |
| `error` | Worker suspended, simulated venue-disconnected message. Quote, refresh, and options reconcile return explicit simulated HTTP-503 error messages in HTTP 409 API responses. |
| `partial` | Synthetic 0.4-of-1 option fill and 12-of-30 SOL perp fill, with retained anchor, pending identifier, suspended worker, and detailed events. Verify actual exposure only includes filled size. This is a presentation fixture; it does not simulate exchange reconciliation. |

Every scenario reset discards the prior QA paper book. None change production mode or data. The normal and empty scenarios refresh through the real paper worker; adverse states stop the worker so they remain stable for visual inspection.

Suggested browser checks:

1. At 1280–1440px width, inspect account strip, risk table, select different assets, and verify the two top-level tabs.
2. In `normal`, quote and buy simulated options, enable the paper hedge, apply a price move, verify a worker event, and pause all. Confirm proposed legs become actual holdings only after purchase.
3. Check Settings, the option purchase confirmation, terminal/pre-expiry plots, actual position details, expanded attribution, and fills.
4. Load each adverse preset and inspect the current state, timestamps, missing-versus-zero values, and feedback after the relevant action.
5. Live production inspection on port 8787 must remain read-only; do not reuse QA action commands against that port.
